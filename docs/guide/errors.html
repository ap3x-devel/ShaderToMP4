When something goes wrongQuand quelque chose ne va pas

ffmpeg not found: the program offers to download it, or you can put ffmpeg next to the program.

No OpenGL 3.3: update the graphics driver. Run the program with --diagnostic on the command line to see what was found.

A compile error shows the file, the line, an explanation and a suggested fix; double-click it in the log to open the file at that line.

The render is slow: look at the GPU cost map in the Images menu and at the render time estimate. Supersampling and motion blur multiply the cost.

ffmpeg introuvable : le programme propose de le télécharger, ou vous pouvez placer ffmpeg à côté du programme.

Pas d'OpenGL 3.3 : mettez à jour le pilote graphique. Lancez le programme avec --diagnostic en ligne de commande pour voir ce qui a été trouvé.

Une erreur de compilation montre le fichier, la ligne, une explication et une correction proposée ; double-cliquez dessus dans le journal pour ouvrir le fichier à cette ligne.

Le rendu est lent : regardez la carte du coût GPU dans le menu Images et l'estimation du temps de rendu. Le sur-échantillonnage et le flou de mouvement multiplient le coût.
