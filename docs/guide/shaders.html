Shadertoy shaders, channels and passesShaders Shadertoy, canaux et passes

An Image shader defines void mainImage(out vec4 fragColor, in vec2 fragCoord). The usual uniforms exist: iResolution, iTime, iTimeDelta, iFrame, iMouse, iDate and iChannel0 to iChannel3.

Give a channel a source with a comment: // iChannel0=noise, // iChannel0=photo.png, // iChannel1=bufferA, // iChannel0=video:clip.mp4.

Passes are files next to the shader: name.bufferA.glsl to name.bufferD.glsl, name.common.glsl and name.cubemapA.glsl; each pass reads the others through its own channels.

A setting is a comment such as // fps=30 or // duration=6; it wins over the video settings for that shader.

Un shader Image définit void mainImage(out vec4 fragColor, in vec2 fragCoord). Les uniforms habituels existent : iResolution, iTime, iTimeDelta, iFrame, iMouse, iDate et iChannel0 à iChannel3.

Donnez une source à un canal par un commentaire : // iChannel0=noise, // iChannel0=photo.png, // iChannel1=bufferA, // iChannel0=video:clip.mp4.

Les passes sont des fichiers à côté du shader : nom.bufferA.glsl à nom.bufferD.glsl, nom.common.glsl et nom.cubemapA.glsl ; chaque passe lit les autres par ses propres canaux.

Un réglage est un commentaire comme // fps=30 ou // duration=6 ; il l'emporte sur les réglages vidéo pour ce shader.
