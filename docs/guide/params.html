Parameters windowFenêtre Paramètres

It shows the parameters declared in the shader with // uniform lines, as sliders, colour pickers or check boxes, and lets you animate each one with keyframes.

A changed value is written back as a comment in the shader file, so the next render uses it.

The post-processing page applies effects such as bloom, grain or colour grading to the finished image.

Elle montre les paramètres déclarés dans le shader par des lignes // uniform, sous forme de curseurs, de sélecteurs de couleur ou de cases à cocher, et permet d'animer chacun par des images clés.

Une valeur modifiée est réécrite sous forme de commentaire dans le fichier du shader : le rendu suivant la prend en compte.

La page de post-traitement applique à l'image terminée des effets comme la lueur, le grain ou l'étalonnage des couleurs.
