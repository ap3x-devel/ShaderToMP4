Editor windowFenêtre Éditeur

Edit the shader with line numbers, colours, search and the list of errors; Ctrl+S saves and the preview refreshes.

The tabs hold the Buffer A to D, Common and Cubemap A passes; the sound page shows the waveform and the beats.

A compile error lists the file and the line, then a short explanation and a suggested fix. The code is never changed unless you change it.

Modifiez le shader avec numéros de ligne, couleurs, recherche et liste des erreurs ; Ctrl+S enregistre et l'aperçu se rafraîchit.

Les onglets contiennent les passes Buffer A à D, Common et Cubemap A ; la page du son montre la forme d'onde et les temps.

Une erreur de compilation indique le fichier et la ligne, puis une courte explication et une correction proposée. Le code n'est jamais modifié sans votre geste.
