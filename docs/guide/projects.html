Projects, queue and shortcutsProjets, file de travaux et raccourcis

A project (.s2mproj) remembers the list of shaders, the general settings, the settings of each shader, the batches, the priorities and the passes and media each shader uses. Use the layers button at the top right: New, Open, Save, Save as, Recent projects. Paths inside the project folder are stored relative, so the whole folder can be moved or copied; a file that is missing when the project opens is listed in the log.

The list is the queue. Drag a shader, or press Alt+Up / Alt+Down, to change the order, even while a render runs: the next job always follows the list. “Hold” puts a job aside until you resume it; “Priority” makes a job render before the others. The status bar gives the estimated end of the whole queue. Each job keeps its own log (right click, “Log of this job”).

The render history lists every finished render with the settings it used; “Redo this render” renders it again with the same settings. The file history.jsonl stays in the program folder and nothing is sent anywhere.

In the preview, the mouse wheel zooms and dragging moves the zoomed image; Ctrl+0 fits the window and Ctrl+1 shows real pixels. “Freeze” keeps the image so the next preview is shown beside it (A/B comparison). “Scopes” shows the histogram, waveform and vectorscope of the displayed image.

Ctrl+K opens the command palette: type a few letters of any command and press Enter. The shortcuts can be changed in keys.ini (menu: Edit shortcuts), then “Reload shortcuts”; a shortcut already used by another command is refused and the log says so.

Un projet (.s2mproj) retient la liste des shaders, les réglages généraux, ceux de chaque shader, les lots, les priorités et les passes et médias que chaque shader utilise. Utilisez le bouton en haut à droite (les couches) : Nouveau, Ouvrir, Enregistrer, Enregistrer sous, Projets récents. Les chemins situés dans le dossier du projet sont notés en relatif : tout le dossier peut être déplacé ou copié ; un fichier absent à l'ouverture est signalé dans le journal.

La liste est la file de travaux. Glissez un shader, ou appuyez sur Alt+Haut / Alt+Bas, pour changer l'ordre, même pendant un rendu : le travail suivant suit toujours la liste. « Suspendre » met un travail de côté jusqu'à sa reprise ; « Priorité » fait passer un travail avant les autres. La barre d'état donne la fin estimée de toute la file. Chaque travail garde son journal (clic droit, « Journal de ce travail »).

L'historique des rendus liste chaque rendu terminé avec les réglages utilisés ; « Refaire ce rendu » le refait avec les mêmes réglages. Le fichier history.jsonl reste dans le dossier du programme et rien n'est envoyé nulle part.

Dans l'aperçu, la molette zoome et le glisser déplace l'image agrandie ; Ctrl+0 ajuste à la fenêtre et Ctrl+1 montre les pixels réels. « Figer » garde l'image pour que l'aperçu suivant s'affiche à côté (comparaison A/B). « Oscilloscopes » montre l'histogramme, la forme d'onde et le vectorscope de l'image affichée.

Ctrl+K ouvre la palette de commandes : tapez quelques lettres d'une commande et appuyez sur Entrée. Les raccourcis se changent dans keys.ini (menu : Modifier les raccourcis), puis « Recharger les raccourcis » ; un raccourci déjà pris par une autre commande est refusé et le journal le dit.
