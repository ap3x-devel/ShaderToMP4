Output windowFenêtre Sortie

Here you choose the kind of file, the colour and HDR options, the audio, the title text, the publication targets, sound and rhythm, loops and the other output tools.

Each page keeps its values in the shader file or in config.ini; the table of settings in the README lists every key.

The size estimate under the codec follows your changes, so you know the weight of the file before you start.

Vous choisissez ici le type de fichier, les options de couleur et de HDR, le son, le texte de titre, les cibles de publication, le son et le rythme, les boucles et les autres outils de sortie.

Chaque page garde ses valeurs dans le fichier du shader ou dans config.ini ; le tableau des réglages du README liste toutes les clés.

L'estimation de taille sous le codec suit vos changements : vous connaissez le poids du fichier avant de commencer.
